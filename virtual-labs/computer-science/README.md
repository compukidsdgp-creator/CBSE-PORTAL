# CBSEMOCK Computer Science Virtual Labs – V7 (Locked Standard)

Complete Class XI and XII collection: 78 browser-native experiments aligned to the CBSE Computer Science (083) 2026–27 topic structure.

## V7 standard
- Preserves the V6 animated workflow in the main learning area.
- Adds concept-specific hands-on experiment panels across all 78 labs.
- Interactive families include logic gates and truth tables; loop and nested-loop pattern generation; list/tuple/dictionary manipulation; string indexing and methods; number-base conversion; flow/decision scenarios; function and stack tracing; text-file pointer simulation; CSV/SQL sample-data exploration; and network packet journeys.
- Reset and challenge controls are included in each experiment.
- Browser-native HTML/CSS/JavaScript/SVG. No backend, Python runtime or external JavaScript dependency.

## Deploy to GitHub Pages
Upload the complete folder contents to a repository. Keep `assets/`, `labs.json`, `index.html`, and all `lab-XX.html` files together. Enable Pages from the repository's main branch and root folder.

## Scope and accuracy
These are interactive concept simulations and guided sample-data exercises, not arbitrary Python execution, a live MySQL server, or a production network. SQL and file operations use local teaching examples. They support learning and practice; they do not replace the CBSE practical record or teacher-supervised practical work.

## QA status
JavaScript syntax checks and package integrity are checked during build. Full device/browser compatibility testing should be completed before classroom-wide deployment.
