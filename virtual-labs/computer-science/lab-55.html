        Aim, theory and procedure
        
  
        
   
        
    
        Aim
        
    
        To write a Python program that implements a stack using a list, with the operations PUSH, POP, PEEK and DISPLAY, and to trace how the stack changes after each operation, including underflow.
        
    
        Requirements
        
    
        A computer or phone with a web browser; Python 3 (here Python 3.12 running in the browser through Pyodide); the task card of operations given for this session.
        
    
        Theory
        
    
        A stack is a linear data structure in which items are added and removed at one end only, called the TOP. The item added last is removed first, so a stack follows LIFO — Last In, First Out — like a pile of plates in the school canteen.
        
    
          
     
        • PUSH adds an item on the top. POP removes the top item and returns it.
          • 
     
        • PEEK (or TOP) returns the top item without removing it. isEmpty tells whether the stack has no items.
          • 
     
        • Trying to POP or PEEK an empty stack is called underflow. Trying to PUSH onto a full fixed-size stack is called overflow; a Python list grows as needed, so overflow happens only if memory runs out.
          • 
    
        
    
        With a Python list, the end of the list is used as the top, because append() and pop() work at the end in constant time:
        
    
        push → stk.append(item)  ·  pop → stk.pop()  ·  peek → stk[-1]
        
    
        index of TOP = len(stk) − 1  ·  size = pushes − successful pops

        Program (complete version)
        
    
        def isEmpty(stk):
    return len(stk) == 0

def push(stk, item):
    stk.append(item)

def pop(stk):
    if isEmpty(stk):
        return None          # underflow
    return stk.pop()

def peek(stk):
    if isEmpty(stk):
        return None
    return stk[-1]

        Precautions
        
    
          
     
        • Always check isEmpty() before popping; pop() on an empty list raises IndexError: pop from empty list.
          • 
     
        • Use pop() with no argument. pop(0) removes the bottom item, which makes the structure behave like a queue (FIFO).
          • 
     
        • Use the same end as the top everywhere: append at the end, pop from the end, peek at index −1.
          • 
     
        • Keep the indentation consistent (4 spaces); Python uses it to decide which lines belong to a function or an if.
          • 
     
        • Test the edge cases: an empty stack, a single item, and several pushes followed by pops.
          • 
    
        
   
        
   
        
    
        Limitations
        
    
          
     
        • A Python list has no fixed size, so overflow cannot be shown here; it is shown with fixed-size arrays in languages such as C.
          • 
     
        • The trace follows only the lines in the editor. Built-in methods such as append() run in one step.
          • 
     
        • A run is stopped after 4000 steps, so an endless loop does not freeze the page.
          • 
     
        • The first run downloads Python (a few megabytes), so it needs an internet connection; later runs are quick. input() is not used because the task card supplies the data.
