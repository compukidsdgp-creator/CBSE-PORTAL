LEARNING OBJECTIVE

Understand repetition

A loop repeats a block of statements while its iteration rule allows it to continue.

What changes when you experiment?

Iteration count controls how many times the body runs.
Start value controls the first value assigned to the loop variable.
Step size controls the change after each iteration.
Nested loops use an inner loop for every outer-loop pass.

Predict challenge

Set rows to 4 and step size to 2. What values will the loop variable take if it starts at 1?
