        Aim, theory and procedure
        
  
        
   
        
    
        Aim
        
    
        To write a Python program that creates a text file, appends a line to it, reads it with read(), readline() and readlines(), counts its vowels, consonants, uppercase and lowercase letters, copies selected lines into another file, and to trace the file pointer using tell() and seek().
        
    
        Requirements
        
    
        A computer or phone with a web browser; Python 3 (here Python 3.12 running in the browser through Pyodide, with its own in-memory disk); the task card of lines given for this session.
        
    
        Theory
        
    
        A text file stores characters. Every line ends with an end-of-line character, written \n in Python. A file must be opened before use and closed afterwards:
        
    
        f = open("story.txt", "r")  …  f.close()
        
    
          
     
        • Modes: "r" read (the default; the file must exist), "w" write (creates the file, or erases an existing one), "a" append (creates it, or adds at the end, keeping old data). "r+", "w+" and "a+" allow both reading and writing.
          • 
     
        • Writing: write(s) writes one string; writelines(L) writes every string of a list. Neither adds \n on its own.
          • 
     
        • Reading: read() gives the rest of the file as one string, read(n) gives at most n characters, readline() gives one line including its \n, and readlines() gives a list of all remaining lines.
          • 
     
        • File pointer: Python remembers where the next read will start. tell() returns that position (counting from 0), and seek(n) moves it to position n. At the end of the file (EOF), read() returns ''.
          • 
     
        • with closes the file automatically: with open(name) as f:.
          • 
    
        
    
        after readline(): tell() = characters in that line, including \n
        
    
        size of file = all characters + one \n per line

        Precautions
        
    
          
     
        • Use "w" only when old data may be lost; use "a" to add to a file.
          • 
     
        • Always close the file (or use with). Written data may stay in a buffer and reach the disk only when the file is closed or flushed.
          • 
     
        • Add "\n" yourself when writing lines; write() and writelines() do not add it.
          • 
     
        • Opening a file that does not exist in "r" mode raises FileNotFoundError; check the file name and folder.
          • 
     
        • Do not call tell() or read() on a closed file; it raises ValueError: I/O operation on closed file.
          • 
    
        
   
        
   
        
    
        Limitations
        
    
          
     
        • Here each character takes one byte and a line ends with one \n. On Windows, Notepad files end lines with two bytes (\r\n), so sizes and tell() values are larger there.
          • 
     
        • In text mode, tell() returns an opaque number for non-English (multi-byte) text; the task card uses English letters only.
          • 
     
        • Inside a for line in f: loop Python reads ahead, so tell() is not allowed there; the pointer view says so.
          • 
     
        • The trace follows only the lines in the editor; built-in methods such as readline() run in one step. The first run downloads Python (a few megabytes), so it needs an internet connection.
