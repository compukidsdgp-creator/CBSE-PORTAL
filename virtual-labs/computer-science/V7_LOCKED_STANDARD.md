# CBSEMOCK V7 – Locked Interactive Virtual Lab Standard

1. Retain V6's premium dark visual identity and continuously animated, concept-native main workflow.
2. Every lab must include an active, concept-appropriate hands-on experiment panel.
3. Inputs must cause visible changes in output, state, table, trace or process.
4. Provide reset and a challenge prompt.
5. Prefer direct manipulation where educationally meaningful (drag/drop, connect, insert, edit, push/pop, query, trace).
6. Preserve responsive layout, readable contrast and keyboard-operable controls wherever possible.
7. No arbitrary Python execution or live database/network claims unless separately implemented and tested.
8. Keep simulations transparent and educationally accurate.
9. New labs and future revisions must follow this standard; do not regress to static-only main work areas.


## Approved reference integrations (release requirement)
- Lab 07: the full drag-and-drop Logic Gate Builder reference, including gate palette, binary inputs, live output and truth table.
- Lab 25: the full Loop Pattern Studio reference, including editable loop bounds, pattern generation and iteration trace.
- Lab 33: the full List Memory Studio reference, including append/insert/update/delete/sort/reverse/search and traversal.
- These are integrated directly into their syllabus experiment pages, not merely shipped as detached demonstrations.
