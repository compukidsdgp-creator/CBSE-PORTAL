CBSEMOCK BIOLOGY VIRTUAL LABS — COLOURFUL INTERACTIVE EDITION V1

Includes 40 standalone Biology lab pages for CBSE Classes 9–12, plus an index homepage.

Each lab includes:
- Colourful responsive interface matching the locked Chemistry V2 design baseline
- Conceptual interactive workspace with condition/focus controls
- Experiment-specific drag-and-drop matching with tap-to-select support
- Correct/incorrect feedback, hints, progress and reset
- Student observation notebook download and print option
- Quick knowledge check
- Advertisement placeholders only (no real ad IDs)

Extract the ZIP and open index.html in a modern browser. Keep all HTML pages in the same folder.

Educational limitation: these are conceptual learning aids, not validated laboratory instruments or replacements for supervised practical work. Some model outputs are qualitative and simplified. Follow teacher instructions and school safety protocols.
