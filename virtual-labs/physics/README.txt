CBSEMOCK — PHYSICS VIRTUAL LABORATORY V4
COMPLETE 40-ACTIVITY COLLECTION

This release retains all 40 Physics activities and the existing index.
Activity 01 is the approved and locked Ohm's Law V3.1 Enhanced Lab.
Activities 02–40 retain their original experiment-specific controls, workbenches,
learning content and quizzes, and now include the Physics V4 Investigation & Assessment Studio.

V4 additions to Activities 02–40:
- Experiment-specific prediction questions and scientific explanations.
- Experiment-specific fault-finding challenges.
- Student observation notebook with manually entered measured values.
- Plotting of recorded independent/dependent variable observations.
- Structured practical report export.
- Teacher assessment rubric and assessment summary export.
- Guided experimental procedure and controlled-variable reminders.

IMPORTANT SCIENTIFIC LIMITATION
The observation notebook in the V4 add-on is deliberately student-entered. It does not
claim to extract readings from every pre-existing simulation's internal model.
The plotted points are the values entered by the student. This makes the source of data
transparent and supports comparison with the original simulation.
Existing experiment models remain educational simulations, not laboratory hardware models.

HOW TO USE
1. Extract the ZIP.
2. Open index.html in a modern browser.
3. Select any experiment.
4. Use the original simulation and the added V4 studio together.
5. Export practical reports and assessment summaries from each activity.

LOCKING / VERSIONING
Ohm's Law V3.1 remains the approved locked reference.
This package is the V4 rollout for the other 39 activities. Future modifications should
be issued as a new release and should not silently overwrite this baseline.
