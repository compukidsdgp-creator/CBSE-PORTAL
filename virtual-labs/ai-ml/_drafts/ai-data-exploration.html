        Aim, theory and procedure

        Aim

        To explore a dataset of Class 10 students’ study habits: find and treat missing, impossible and duplicate records; calculate descriptive statistics; use a histogram and scatter plots to find patterns; and check the strongest pattern by training and testing a simple straight-line model.

        Apparatus / requirements

        A computer or phone with a browser; the dataset class10_study_habits.csv (41 records × 7 columns: Roll, StudyHours, SleepHours, ScreenHours, Attendance, Height_cm, Marks); a calculator; the practical file. To repeat it in Python: Python 3 with the pandas and matplotlib libraries.

        Theory

        Data exploration is the stage of the AI project cycle that comes after data acquisition and before modelling. We look at the data with statistics and graphs to check its quality and to find patterns, so we know which features are worth giving to a model.

        Cleaning. Real data has missing values (blank cells), impossible values (a typing slip such as 930% attendance) and duplicate records. A blank feature can be filled with the column’s median, which outliers do not pull. A blank target (Marks) must never be guessed — that row is dropped.

        x̄ = Σx ÷ n  ·  Range = max − min

        Median = value at position (n + 1)/2 of the sorted list
        (n even → average of the n/2-th and (n/2 + 1)-th values)

        σ = √[ Σ(x − x̄)² ÷ n ] = √( Σx²/n − x̄² )

        Mode is the most frequent value. A histogram shows how one numeric column is spread out; a scatter plot shows whether two columns move together.

        Correlation r (enrichment, Class 11) measures how close the dots are to a straight line, from −1 (falls perfectly) through 0 (no pattern) to +1 (rises perfectly):

        r = Σ(x − x̄)(y − ȳ) ÷ √[ Σ(x − x̄)² · Σ(y − ȳ)² ]

        Straight-line model. Least squares gives the line ŷ = m·x + c with m = Σ(x − x̄)(y − ȳ) ÷ Σ(x − x̄)² and c = ȳ − m·x̄. It learns from 80% of the records (training set) and is judged on the 20% it has never seen (test set) using the mean absolute error, MAE = Σ|y − ŷ| ÷ n.

        Procedure

        1. Open the dataset and note its size (rows × columns) and the meaning and unit of every column. Identify the target (Marks) and the features.
        2. Sort each column. Blanks collect at the bottom; impossible values show up at the top or bottom.
        3. Remove the repeated record (sort by Roll), drop the record with no Marks, correct the decimal slips, and fill blank feature cells with the column median.
        4. Press “Check my cleaning” and complete the cleaning log (Table 1).
        5. For Marks and at least two other columns, read n, Σx, Σx² and the sorted values in the inspector. Calculate the minimum, maximum, mean, median, mode and σ, and enter them in Table 2.
        6. Draw the histogram of Marks and note the modal class and where the mean and median lie.
        7. Plot each feature against Marks. Record in Table 3 whether Marks rise, fall or show no clear pattern.
        8. Train a straight-line model on the feature with the strongest pattern. Note its equation and its test MAE, and compare with the other features and with simply guessing the mean.
        9. Write the result and the limitations in the practical file.

        The same steps in Python

        Code for your practical file. It is not run on this page — download the raw CSV above and run it in your own Python.

        import pandas as pd
import matplotlib.pyplot as plt
df = pd.read_csv('class10_study_habits.csv')
print(df.shape)                # rows, columns
print(df.isnull().sum())       # blanks per column
df = df.drop_duplicates()
df = df.dropna(subset=['Marks'])          # never guess the target
df.loc[df['Attendance'] > 100, 'Attendance'] /= 10
df.loc[df['SleepHours'] > 24, 'SleepHours'] /= 10
df = df.fillna(df.median(numeric_only=True))
print(df['Marks'].mean(), df['Marks'].median(), df['Marks'].mode().tolist())
print(df['Marks'].std(ddof=0))            # σ with n
plt.hist(df['Marks'], bins=range(0, 101, 10)); plt.show()
plt.scatter(df['StudyHours'], df['Marks']); plt.show()
print(df.corr(numeric_only=True)['Marks'])

        Precautions

        • Keep an untouched copy of the raw data; clean a copy.
        • Check every column against its unit before calculating (attendance ≤ 100%, sleep ≤ 24 h).
        • Never fill the target column with a guess; drop that record.
        • Finish cleaning before calculating statistics, and use the same cleaned data for every table and graph.
        • Use n (not n − 1) for σ, as in CBSE textbooks, and state it. (pandas’ .std() uses n − 1 unless you write ddof=0.)
        • Never test a model on the records it was trained on.

        Limitations (sources of error)

        • The sample is small (about 40 students), so r and the model change noticeably with a different 80 / 20 split.
        • Filling blanks with the median slightly reduces the spread (σ) of that column.
        • Correlation does not prove cause: a pattern between two columns may be due to a third factor.
        • A one-feature straight-line model ignores the other habits that also affect marks, so its error cannot reach zero.
        • The dataset on this page is simulated: each session generates new records from a hidden rule plus random noise, so your answers cannot be copied. The model, statistics and graphs are calculated for real from those records.
