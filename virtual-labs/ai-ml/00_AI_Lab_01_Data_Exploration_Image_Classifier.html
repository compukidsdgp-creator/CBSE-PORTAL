INVESTIGATION CONTROLS
Learning goal
Discover how feature values influence a model's classification, and why accuracy alone does not tell the whole story.
Required columns: brightness,roundness,texture,label. Feature values should be between 0 and 1. A stratified 75/25 split is used, keeping each class represented in training and testing where possible.
Teaching model: the built-in dataset is synthetic and uses simplified numerical image features. It is not a production vision model and does not identify real photographs.
