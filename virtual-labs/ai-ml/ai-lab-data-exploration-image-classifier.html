    Aim, theory and procedure

    Aim

    To explore and clean an image dataset of handwritten digits, train a k-nearest-neighbours (k-NN) classifier on it, and evaluate the model using a confusion matrix, accuracy, precision and recall.

    Apparatus / requirements

    A computer or phone with a web browser; the dataset of 8×8 handwritten-digit images built into this page; the k-NN model, which is trained by JavaScript inside this page (nothing is sent to a server).

    Dataset: 1,000 of the 1,797 images in the UCI “Optical Recognition of Handwritten Digits” dataset (E. Alpaydin and C. Kaynak, 1998, CC BY 4.0), 100 of each digit, written by 43 people. Each session hides 150 of them as an unseen batch and adds a few faulty records, as happens in real data collection.

    Theory

    Data exploration is the stage of the AI project cycle (problem scoping → data acquisition → data exploration → modelling → evaluation → deployment) where we look at the data, count it, plot it and find problems before modelling.

    An image is a grid of numbers. Each digit was scanned as 32×32 black-and-white dots. The dots were grouped into 4×4 blocks and the inked dots in each block counted, giving an 8×8 image whose 64 pixel values run from 0 (blank) to 16 (fully inked).

    k-NN stores the labelled training images. To classify a new image it finds the k training images nearest to it and takes a majority vote. Nearness is the Euclidean distance between feature vectors:

    d = √[(x₁−y₁)² + (x₂−y₂)² + … + (xₙ−yₙ)²]

    A tie in the vote goes to the class of the nearest neighbour.

    Evaluation. In the confusion matrix, each row is an actual digit and each column a predicted digit; correct predictions lie on the diagonal. For one digit, a true positive (TP) is a correct “yes”, a false positive (FP) a wrong “yes” and a false negative (FN) a missed one.

    Accuracy = correct ÷ total × 100

    Precision = TP ÷ (TP + FP)  ·  Recall = TP ÷ (TP + FN)

    F1 score = 2 × Precision × Recall ÷ (Precision + Recall)

    Procedure

    1. Open each digit in the gallery and look at the images. Note any blank images and any image whose label clearly does not match the digit shown.
    2. Use the data checks to count the total records, the blank images and the exact duplicates. Write these and the number of mislabelled images in Table 1.
    3. Correct every mislabelled image, then remove the blank images and the duplicates.
    4. In Step 2, choose a feature set (64 pixels, 16 pooled blocks or 3 simple features) and a train : test ratio.
    5. In Step 3, choose k, train the model and evaluate it on the test set.
    6. Read the confusion matrix: add all its cells for the number of images evaluated and add the diagonal for the number of correct predictions. Record the trial and type both readings in Table 2.
    7. Repeat for at least four values of k, and compare the feature sets.
    8. Work out precision and recall for the digit you are given, from a test-set matrix.
    9. Plot accuracy against k, choose the best settings and check them on the unseen batch.
    10. Draw your own digits in Step 4 and see how the model treats handwriting it has never met.

    Precautions

    • Explore and clean the data before training; never train on records you have not checked.
    • Keep the test set separate. Accuracy measured on the training images is not a fair test.
    • Use a stratified split so every digit appears in both the training and the test set.
    • Remove duplicates before splitting, so that the same image cannot appear in both sets.
    • Change one setting at a time (k, feature set or split) so you know what caused a change in accuracy.
    • Correct a label only when the image clearly shows another digit; 8×8 images can look rough.

    Limitations and sources of error

    • Accuracy depends on which images land in the test set; a different split gives a slightly different value.
    • Mislabelled training images that were missed still mislead the model, especially when k = 1.
    • 8×8 images lose detail, so some 1s and 7s, or 3s, 8s and 9s, really do look alike.
    • The model only knows the handwriting styles of 43 writers; very different handwriting (or a small, off-centre drawing) is often misclassified.
    • Accuracy alone hides which digits fail; precision and recall per digit tell more.
    • k-NN must compare each new image with every training image, so it becomes slow on very large datasets.
