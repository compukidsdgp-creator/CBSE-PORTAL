CBSEMOCK QUEST — LOCKED VISUAL EDITION

This edition applies the selected airy, dimensional 3D-inspired interface:
- Blue/lavender gradient environment with bright, readable white surfaces
- Branded header and labelled navigation rail
- Soft raised cards, rounded controls and clear answer states
- Quiz layout with question panel and progress/XP side cards
- Responsive layout for desktop, tablet and mobile

The underlying quiz engine, question rendering, scoring, local progress, certificate threshold, export/import and JSON catalogue loading are retained.

Included release data: November 2026 Classes 9–10 Batch 1 (9 subject quests, 14 class-specific banks, 15 questions per bank). Academic syllabus mapping caveats remain as described in the Batch 1 review workbook/README; structural validation is not a substitute for academic review.

LOCAL TEST
1. Extract this ZIP.
2. Open the CBSEMOCK_Quest_Local_Test folder.
3. Double-click RUN-LOCAL.bat.
4. Keep the command window open while testing.
5. Open the local address shown by the launcher (normally http://localhost:8000).

MONTHLY CONTENT UPDATES
For later monthly releases, replace only the data folder with a complete release data folder. Keep the catalogue, manifests and all referenced question-bank JSON files together. To retain the archive, include prior releases in the new data folder's catalogue and question paths.

GITHUB PAGES
Upload the contents of CBSEMOCK_Quest_Local_Test to the intended repository folder. GitHub Pages serves index.html and the assets/data folders as static files.

STORAGE NOTE
Student progress is stored in that browser's local storage. This standalone build does not provide a central leaderboard or centrally verifiable certificates.
