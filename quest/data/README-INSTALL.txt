CBSEMOCK QUEST — COMBINED NOVEMBER DATA
======================================

This package is a merged data folder for the working 3D Quest application.

It retains the existing Classes 9–10 November content and adds the Classes
11–12 Physics, Chemistry, Biology and Mathematics Batch 2 content.

INSTALLATION
1. Make a backup copy of your application's current data folder.
2. Extract this ZIP.
3. Copy the included "data" folder into your application folder, replacing
   the existing data folder when prompted.
4. Keep index.html, assets/quest.css, assets/quest.js and RUN-LOCAL.bat unchanged.
5. Restart the local server and refresh the browser with Ctrl+F5.

IMPORTANT
- Do NOT copy the Batch 2 catalogue-entry.json by itself over the existing
  catalogue. This package already contains a merged catalogue.
- The four new Group 11–12 quests are Physics, Chemistry, Biology and
  Mathematics. Each manifest routes Class 11 and Class 12 to its own bank.
- Existing Classes 9–10 files have been retained.
- Content is still draft pending academic review; do not publish as final
  until the syllabus and question quality checks are complete.

CHECKS
- Catalogue entries: 13 (9 existing Classes 9–10 + 4 new Classes 11–12)
- New banks: 8 (4 subjects x 2 classes), 15 questions per bank
- New manifests: 4
- All catalogue manifest paths and manifest bank paths checked.
