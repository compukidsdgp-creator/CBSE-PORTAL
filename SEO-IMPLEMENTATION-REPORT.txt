REMAINING ACCOUNT-OWNER ACTIONS
-------------------------------
The ZIP cannot change registrar DNS or GitHub repository settings. Complete
these actions using SEO-DEPLOYMENT-GUIDE.txt:

- Configure apex DNS A records and recommended AAAA records.
- Optionally configure www as a CNAME to the GitHub Pages account host.
- In GitHub Settings -> Pages, set cbsemock.org.in as the custom domain.
- Wait for DNS verification and enable Enforce HTTPS.
- Verify the site in Google Search Console and submit sitemap.xml.

Google controls crawling, indexing and rankings. A sitemap submission or
structured data does not guarantee indexing or a particular search position.
