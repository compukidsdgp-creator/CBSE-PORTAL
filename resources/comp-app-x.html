💻 Computer Fundamentals
Computer Organisation · Input/Output · Memory · Software · Operating System · Cyber Safety

📖 Core Theory

Computer Organisation

A computer system consists of: Input Unit (keyboard, mouse, scanner), CPU (Control Unit + ALU + Registers), Memory (RAM, ROM), Output Unit (monitor, printer). CPU is the "brain" — executes instructions. ALU does arithmetic and logical operations. Control Unit coordinates all operations.

CPU Components
ALU (Arithmetic Logic Unit): performs +,-,×,÷ and comparisons. Control Unit: fetches, decodes, executes instructions. Registers: small, fast storage inside CPU (Accumulator, PC, IR, MAR, MDR).
RAM vs ROM
RAM (Random Access Memory): volatile, read-write, primary memory. ROM (Read Only Memory): non-volatile, permanently stores BIOS. Cache memory: fastest, between CPU and RAM.
Memory Units
1 Byte = 8 bits. 1 KB = 1024 Bytes. 1 MB = 1024 KB. 1 GB = 1024 MB. 1 TB = 1024 GB. ASCII: 8-bit code for characters. Unicode: 16-bit, multilingual.
Operating System
Software that manages hardware and provides user interface. Functions: process management, memory management, file management, I/O management. Examples: Windows, Linux, macOS, Android.

🔑 Key Facts — Computer Fundamentals

Binary: base 2 (0,1). Decimal to binary: divide repeatedly by 2, read remainders upwards.
Octal: base 8. Hexadecimal: base 16 (0-9, A-F where A=10...F=15).
1's complement: invert all bits. 2's complement: invert + add 1 (used for negative numbers).
Boolean: AND (A.B), OR (A+B), NOT (A'), NAND, NOR, XOR. De Morgan's: (A.B)' = A'+B'

SA (3M) Distinguish between RAM and ROM with any three points.
Ans: RAM (Random Access Memory): (1) Volatile — data lost when power is off. (2) Read-write memory — can be both read and modified. (3) Used for storing data and programs currently in use (primary/temporary memory). ROM (Read Only Memory): (1) Non-volatile — retains data even without power. LA (5M) Explain the functions of an Operating System. Give two examples.
Ans: An Operating System (OS) is system software that acts as an interface between the user and the computer hardware. Functions: (1) Process Management: Manages running programs — scheduling CPU time, creating and terminating processes. (2) Memory Management: Allocates and deallocates memory to programs; manages virtual memory. (3) File Management: Organises files in directories, controls file access and security. (4) Device Management: Manages I/O devices through device drivers — keyboard, printer, monitor. (5) Security and Access Control: Protects the system through user authentication, passwords, and permissions. Examples: Windows 11 (Microsoft) and Ubuntu Linux (open-source). Both manage these five functions but with different interfaces and licensing models.
🐍 Python Programming
Data Types · Control Flow · Functions · Strings · Lists · Tuples · Dictionaries · File Handling

📖 Core Theory

Python Basics

Python is an interpreted, high-level, object-oriented language. Dynamically typed (no explicit type declaration). Indentation defines code blocks. Key data types: int, float, str, bool, list, tuple, dict, set. print() for output, input() for input (returns string).

List vs Tuple
List: mutable, ordered, allows duplicates. L=[1,2,3]. Tuple: immutable, ordered, allows duplicates. T=(1,2,3). Lists use square brackets, tuples use parentheses.
Dictionary
Key-value pairs. D = {'name': 'Ali', 'age': 15}. Keys must be unique and immutable. Access: D['name']. Methods: keys(), values(), items(), get(), update().
String Methods
s.upper(), s.lower(), s.strip(), s.split(), s.replace(old,new), s.find(sub), s.count(sub), s.startswith(), s.endswith(), len(s), s[i], s[i:j].
Control Flow
if-elif-else for conditions. for loop: iterates over sequence. while loop: runs while condition true. break: exit loop. continue: skip rest of loop body. range(start, stop, step).

🔑 Python Syntax Reference

Function: def myFunc(param): ... return value
File read: f = open("file.txt","r"); data = f.read(); f.close()
File write: f = open("file.txt","w"); f.write("hello"); f.close()
List ops: append(), insert(i,v), remove(v), pop(i), sort(), reverse(), len()

🗄️ Database Management (SQL)
RDBMS Concepts · SQL Commands · DDL · DML · Queries · Aggregate Functions

📖 Core Theory

RDBMS and SQL

RDBMS: data stored in tables (rows and columns). Table = Relation; Row = Tuple/Record; Column = Attribute/Field. Key concepts: Primary Key (unique, not null), Foreign Key (links to another table). SQL = Structured Query Language.

DDL vs DML
DDL (Data Definition Language): CREATE TABLE, ALTER TABLE, DROP TABLE. DML (Data Manipulation Language): INSERT, UPDATE, DELETE, SELECT. These are the two categories of SQL commands.
SELECT Syntax
SELECT col1, col2 FROM tablename WHERE condition ORDER BY col ASC/DESC; * selects all columns. WHERE filters rows. ORDER BY sorts results.
Aggregate Functions
COUNT(*): counts rows. SUM(col): sum of values. AVG(col): average. MAX(col): maximum. MIN(col): minimum. Used with GROUP BY to summarise groups.
Joins (Basic)
Cartesian Product: SELECT * FROM T1, T2 — all combinations. Equijoin: SELECT * FROM T1, T2 WHERE T1.key = T2.key — matching rows only.

🔑 SQL Quick Reference

CREATE TABLE Student(RollNo INT PRIMARY KEY, Name VARCHAR(30), Marks INT);
INSERT INTO Student VALUES(1, 'Ali', 95);
SELECT Name, Marks FROM Student WHERE Marks > 80 ORDER BY Marks DESC;
UPDATE Student SET Marks=98 WHERE RollNo=1;

🌐 Networking and Cyber Safety
Types of Networks · Protocols · Internet · Cyber Crime · Cyber Ethics

📖 Core Theory

LAN vs WAN
LAN (Local Area Network): small area (building, campus). MAN (Metropolitan): city-wide. WAN (Wide Area Network): large geographic area — the Internet is the largest WAN.
Protocols
HTTP: web pages. HTTPS: secure web. FTP: file transfer. SMTP: email sending. POP3/IMAP: email receiving. TCP/IP: fundamental internet protocol suite.
IP Address
Unique 32-bit address for each device on internet (IPv4: e.g., 192.168.1.1). DNS translates domain names (www.google.com) to IP addresses. MAC address: physical address of network card.
Cyber Threats
Malware (virus, worm, trojan, ransomware). Phishing (fake emails/sites to steal data). Hacking. Cyberbullying. Identity theft. Spam. Prevention: antivirus, strong passwords, 2FA, SSL.

🔑 Networking Quick Facts

Transmission media: twisted pair (telephone), coaxial cable, optical fibre (fastest, least interference)
Topology: Bus, Star, Ring, Mesh, Tree. Star most common in LANs (easy to manage)
Bandwidth: max data transmitted per second. Mbps = megabits per second.
Cyber ethics: do not copy software illegally; protect personal data; respect others online

Example 1 — Networking (Board 2022, 3M)

1

Uses: (1) Packet Filtering — examines each data packet and blocks those that don't meet the security criteria (e.g., packets from unauthorised IP addresses). (2) Application-level Control — blocks access to specific websites or services (e.g., blocking social media sites in an office). Without a firewall, the network is vulnerable to unauthorised access, hacking, and data theft.
🌐 HTML and Web Development
HTML Tags · Tables · Forms · CSS Basics · Javascript Basics

📖 Core Theory

HTML Structure
html → head → (title, style, meta) + body → (all visible content). Tags: opening tag + content + closing tag. Self-closing: br, img, hr, input.
Text Formatting
h1-h6 (headings), p (paragraph), b/strong (bold), i/em (italic), u (underline), sup (superscript), sub (subscript), br (line break), hr (horizontal rule).
Tables
table → tr (row) → th (header cell) or td (data cell). Attributes: border, width, cellpadding, cellspacing, colspan, rowspan, align.
Forms
form → input (text, password, radio, checkbox, submit, reset), select (dropdown) + option, textarea. Attributes: action, method (GET/POST), name, value.

🔑 HTML Reference

Link: a href="url" target="_blank" — opens in new tab
Image: img src="pic.jpg" alt="desc" width="200" height="150"
Table cell spanning: td colspan="2" — spans 2 columns; rowspan="2" — spans 2 rows
CSS inline: style="color:red; font-size:16px; background-color:yellow"

❌ Mistake Bank — Computer Applications
Most common errors in Comp App boards — catch these before the examiner does
Python — Indentation Errors
Mistake: Writing function body without consistent indentation — Python throws IndentationError.
Fix: Always use 4 spaces (or 1 Tab) consistently. The most common reason for zero marks in a code question is indentation mismatch.
SQL — Missing Semicolon / Wrong Quotes
Mistake: Writing string values with double quotes in SQL — WHERE Name="Ram" is wrong. SQL uses single quotes: WHERE Name='Ram'.
Fix: String values = single quotes. Column names / keywords = no quotes. Every SQL statement ends with semicolon.
Python — range() Off-by-One
Mistake: Writing range(1, n) when you mean to include n — range(1,n) gives 1 to n-1.
Fix: range(1, n+1) gives 1 to n. Always trace your loop with a small value of n before writing final answer.
HTML — Unclosed Tags
Mistake: Opening <table> without closing </table>, or <tr> without </tr> — loses 1 mark per unclosed tag.
Fix: Write opening and closing tags together first, then fill the content. Count <tr> = count </tr>.
Networking — Confusing Terms
Mistake: Writing "IP address is the physical address" — IP is logical, MAC is physical.
Fix: IP = logical (can change), MAC = physical (hardware, fixed). DNS converts domain name → IP address. HTTP = port 80, HTTPS = port 443.
Python — print() vs return
Mistake: Using print() inside a function when question asks to "return" the value — both look correct but only return passes value back to caller.
Fix: If question says "function should return", use return. If it says "display", use print(). Read the question keyword carefully.
📓 Code Tracing Strategy: For every Python program you write in exam, trace it mentally with a simple example (e.g., n=5, list=[3,1,4]) before writing. This catches 80% of logic errors before submission.

Python Code Marking (3-mark)

Definitions (1-2 mark)
