About this chapter

Class 12 probability builds on basic probability with conditional probability, the multiplication theorem, independent events, the theorem of total probability and Bayes' theorem, along with random variables and their probability distributions. Bayes' theorem questions — such as finding the chance that an item came from a particular machine — appear in almost every board paper.

Answers & explanations — Probability

Try the quiz above first, then open each question to check the answer and the reasoning.

Q1. P(A∪B) = P(A) + P(B) if A and B are:
  1. Independent events
  2. Mutually exclusive events
  3. Exhaustive events
  4. Equally likely events

Answer: (B) Mutually exclusive events — If A∩B = ∅ (mutually exclusive), then P(A∪B) = P(A) + P(B). Otherwise P(A∪B) = P(A)+P(B)−P(A∩B).

Q2. Bayes' theorem finds:
  1. Total probability
  2. Posterior probability given prior probability and likelihood
  3. Joint probability
  4. Conditional probability of cause given effect

Answer: (D) Conditional probability of cause given effect — Bayes' theorem: P(A|B) = P(B|A)P(A)/P(B). It updates probability of a hypothesis given evidence.

Q3. If P(A) = 0.6 and P(B) = 0.5 and A, B are independent, then P(A∩B) =
  1. 0.3
  2. 0.11
  3. 0.8
  4. 0.1

Answer: (A) 0.3 — Independent: P(A∩B) = P(A)×P(B) = 0.6×0.5 = 0.3.

Q4. For a binomial distribution, mean = np and variance =
  1. np
  2. np(1−p)
  3. n²p
  4. np²

Answer: (B) np(1−p) — Binomial: mean μ = np, variance σ² = npq = np(1−p).

Q5. P(A|B) = P(A∩B)/P(B). This is defined when:
  1. P(A) > 0
  2. P(B) > 0
  3. P(A∩B) > 0
  4. P(A)+P(B) = 1

Answer: (B) P(B) > 0 — Conditional probability P(A|B) requires P(B) > 0 (can't condition on impossible event).

Q6. Total probability theorem: P(B) = ΣP(B|Aᵢ)P(Aᵢ) for partition {Aᵢ}. This assumes:
  1. Events Aᵢ are independent
  2. Events Aᵢ form a partition (mutually exclusive, exhaustive)
  3. P(B) = 1
  4. All P(Aᵢ) are equal

Answer: (B) Events Aᵢ form a partition (mutually exclusive, exhaustive) — Total probability requires {Aᵢ} to be a complete partition: mutually exclusive and exhaustive.

Q7. A fair die is rolled. P(getting 6 | getting even number) =
  1. 1/6
  2. 1/3
  3. 1/2
  4. 1/4

Answer: (B) 1/3 — P(6|even) = P(6∩even)/P(even) = P(6)/P(even) = (1/6)/(3/6) = 1/3.

Q8. If E(X) = μ, then E(X−μ)² is:
  1. μ²
  2. 0
  3. Var(X)
  4. E(X)²

Answer: (C) Var(X) — Variance = E[(X−μ)²]. This is the definition of variance.

Q9. Poisson distribution is a limiting case of binomial when:
  1. n is small, p is large
  2. n→∞ and p→0 with np = λ constant
  3. n = p
  4. n and p are both large

Answer: (B) n→∞ and p→0 with np = λ constant — Poisson approximation: n large, p small, np = λ finite. P(X=k) = e⁻λλᵏ/k!

Q10. Two cards are drawn without replacement from a pack. P(both aces) =
  1. 1/13
  2. 4/52×4/52
  3. 4/52×3/51
  4. 1/221

Answer: (C) 4/52×3/51 — P = 4/52 × 3/51 = 12/2652 = 1/221. After removing one ace, 3 remain from 51 cards.

Q11. P(A') = 1 − P(A) is called:
  1. Bayes' formula
  2. Complement rule
  3. Total probability
  4. Addition theorem

Answer: (B) Complement rule — Complement rule: P(Aᶜ) = P(A') = 1 − P(A).

Q12. In a random experiment, sample space S is the set of all:
  1. Favourable outcomes
  2. Possible outcomes
  3. Equally likely outcomes
  4. Independent outcomes

Answer: (B) Possible outcomes — Sample space S is the set of all possible outcomes of a random experiment.
