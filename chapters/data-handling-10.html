About this chapter

Data is the fuel of every AI system. This chapter explains how data is collected, cleaned and organised, and how charts such as bar graphs, line graphs, pie charts and histograms reveal patterns before a model is built. You will also meet simple statistical measures — mean, median and mode — and learn why missing or biased data leads to poor AI decisions.

Answers & explanations — Data Handling & Visualisation

Try the quiz above first, then open each question to check the answer and the reasoning.

Q1. Pandas library is used for:
  1. Creating animations
  2. Data manipulation and analysis using DataFrames
  3. Deep learning
  4. Web development

Answer: (B) Data manipulation and analysis using DataFrames — Pandas: Python library for data manipulation. Key structures: DataFrame (table) and Series (column).

Q2. A DataFrame in Pandas is:
  1. A 1D array
  2. A 2D table with labelled rows and columns
  3. A list
  4. A dictionary with one key

Answer: (B) A 2D table with labelled rows and columns — DataFrame: 2D labelled data structure like a spreadsheet. Rows and columns have labels (index and column names).

Q3. To read a CSV file into a DataFrame:
  1. pd.open_csv('file.csv')
  2. pd.read_csv('file.csv')
  3. pd.load('file.csv')
  4. pd.csv('file.csv')

Answer: (B) pd.read_csv('file.csv') — pd.read_csv('filename.csv') reads a CSV file and returns a DataFrame. It's the most used Pandas function.

Q4. df.head() in Pandas shows:
  1. Last 5 rows
  2. First 5 rows by default
  3. Column names only
  4. Data types

Answer: (B) First 5 rows by default — df.head(n) shows first n rows (default n=5). df.tail() shows last rows.

Q5. df.describe() gives:
  1. First row
  2. Data types of columns
  3. Statistical summary (count, mean, std, min, max)
  4. Shape of DataFrame

Answer: (C) Statistical summary (count, mean, std, min, max) — df.describe() generates descriptive statistics: count, mean, std, min, 25%, 50%, 75%, max for numeric columns.

Q6. A bar chart is best used to:
  1. Show distribution of continuous data
  2. Compare categorical data
  3. Show correlation between two variables
  4. Display time series

Answer: (B) Compare categorical data — Bar charts compare quantities across categories (e.g., scores of different students, sales by month).

Q7. A scatter plot is used to show:
  1. Parts of a whole
  2. Relationship/correlation between two numerical variables
  3. Trend over time only
  4. Frequency distribution

Answer: (B) Relationship/correlation between two numerical variables — Scatter plot: plots (x,y) points to visualise correlation between two continuous variables.

Q8. Missing values in a DataFrame can be found using:
  1. df.missing()
  2. df.isnull().sum()
  3. df.find_null()
  4. df.check()

Answer: (B) df.isnull().sum() — df.isnull() returns True where values are NaN. .sum() counts missing values per column.

Q9. plt.show() in Matplotlib:
  1. Saves the chart
  2. Displays the chart
  3. Clears the chart
  4. Creates a new figure

Answer: (B) Displays the chart — plt.show() renders and displays the plot. Without it, the chart may not appear in some environments.

Q10. To drop a column 'Age' from DataFrame df:
  1. df.remove('Age')
  2. df.drop('Age', axis=1)
  3. df.delete('Age')
  4. del df['Age'] only

Answer: (B) df.drop('Age', axis=1) — df.drop('Age', axis=1) drops a column (axis=1). axis=0 drops rows. Add inplace=True to modify in place.

Q11. Data normalisation in ML means:
  1. Making all values equal
  2. Scaling features to a common range (e.g., 0 to 1)
  3. Removing all data
  4. Adding more data

Answer: (B) Scaling features to a common range (e.g., 0 to 1) — Normalisation scales features to same range so no single feature dominates due to scale difference.

Q12. A pie chart is best for showing:
  1. Trend over time
  2. Relationship between variables
  3. Parts of a whole (proportions)
  4. Distribution of data

Answer: (C) Parts of a whole (proportions) — Pie chart: shows proportions/percentages of a whole. Good for categorical data summing to 100%.
