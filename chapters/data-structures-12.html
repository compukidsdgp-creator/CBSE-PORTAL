About this chapter

A data structure organises data so that a program can use it efficiently. The CBSE syllabus focuses on the stack, a Last-In-First-Out structure, implemented in Python with a list: push using append() and pop using pop(). Board questions ask you to write push and pop functions, trace a sequence of operations, or apply a stack to reverse a string or check balanced brackets.

Answers & explanations — Data Structures — Stack & Queue

Try the quiz above first, then open each question to check the answer and the reasoning.

Q1. A stack follows which principle?
  1. FIFO
  2. LIFO
  3. Random access
  4. Priority based

Answer: (B) LIFO — Stack: Last In First Out (LIFO). The last element pushed is the first to be popped.

Q2. Which Python list method is used to add an element to a stack?
  1. insert()
  2. append()
  3. push()
  4. enqueue()

Answer: (B) append() — In Python, list.append(x) adds to the end (top of stack). pop() removes from the end.

Q3. A queue follows which principle?
  1. LIFO
  2. FIFO
  3. Random
  4. FILO

Answer: (B) FIFO — Queue: First In First Out (FIFO). First element added is the first to be removed.

Q4. In a stack implemented using a list, pop() removes from:
  1. Beginning
  2. Middle
  3. End (top)
  4. Random position

Answer: (C) End (top) — list.pop() removes and returns the last element — the top of the stack.

Q5. Overflow condition in a stack occurs when:
  1. Stack is empty and pop is called
  2. Stack is full and push is called
  3. Queue is empty
  4. Index is negative

Answer: (B) Stack is full and push is called — Overflow: trying to push onto a full stack. Underflow: trying to pop from an empty stack.

Q6. Which real-world scenario best represents a queue?
  1. Undo operation in editor
  2. Browser back button
  3. Ticket counter line
  4. Call stack in recursion

Answer: (C) Ticket counter line — Queue = first-come-first-served. Ticket counter: first person in line is served first (FIFO).

Q7. In Python, deque from collections is preferred for queue because:
  1. It is slower
  2. pop(0) on list is O(n); deque.popleft() is O(1)
  3. Lists don't support append
  4. deque has no size limit

Answer: (B) pop(0) on list is O(n); deque.popleft() is O(1) — list.pop(0) shifts all elements — O(n). deque.popleft() is O(1), making it efficient for queue operations.

Q8. The operation to view the top element of stack without removing it is called:
  1. pop
  2. push
  3. peek
  4. enqueue

Answer: (C) peek — Peek (or top): returns the top element without removing it. In Python: stack[-1].

Q9. Infix expression A+B*C is evaluated as A+(B*C) because:
  1. Left to right always
  2. Operator precedence (* before +)
  3. Stack is FIFO
  4. It's postfix

Answer: (B) Operator precedence (* before +) — Operator precedence: * has higher precedence than +, so B*C is evaluated first.

Q10. A linked list node contains:
  1. Data only
  2. Pointer only
  3. Data and pointer to next node
  4. Two data values

Answer: (C) Data and pointer to next node — Each linked list node stores: data (the value) and a pointer/reference to the next node.

Q11. Time complexity of push and pop operations in a stack is:
  1. O(n)
  2. O(log n)
  3. O(1)
  4. O(n²)

Answer: (C) O(1) — Push and pop at the top of a stack are O(1) — constant time, no shifting needed.

Q12. Which data structure is used to implement function call recursion?
  1. Queue
  2. Array
  3. Stack
  4. Tree

Answer: (C) Stack — Call stack: each function call is pushed; when it returns, it's popped. Recursion uses the system stack.
