About this chapter

An arithmetic progression is a list of numbers with a constant difference between consecutive terms. The chapter rests on two formulas — the nth term aₙ = a + (n − 1)d and the sum Sₙ = n/2 [2a + (n − 1)d] — and on reading word problems about savings, instalments or rows of seats as an AP. Questions often ask for a missing term, the number of terms, or which term of the AP equals a given value.

Answers & explanations — Arithmetic Progressions

Q1. The nth term of an AP with first term a and common difference d is:
  1. a + nd
  2. a + (n−1)d
  3. na + d
  4. a − (n−1)d

Answer: (B) a + (n−1)d — aₙ = a + (n−1)d. First term a, adding d a total of (n−1) times to reach nth term.

Q2. Sum of first n terms of AP: Sₙ =
  1. n(a+l)/2
  2. n/2 × (2a+(n−1)d)
  3. Both A and B
  4. na + nd²

Answer: (C) Both A and B — Sₙ = n(a+l)/2 (where l = last term) = n/2×(2a+(n−1)d). Both are equivalent.

Q3. Find the 20th term of AP: 3, 7, 11, 15, ...
  1. 79
  2. 77
  3. 75
  4. 81

Answer: (A) 79 — a=3, d=4. a₂₀ = 3 + 19×4 = 3 + 76 = 79.

Q4. If a₅ = 17 and a₉ = 33, the common difference d =
  1. 2
  2. 4
  3. 8
  4. 16

Answer: (B) 4 — a₉ − a₅ = 4d = 33 − 17 = 16 → d = 4.

Q6. The sum 1 + 2 + 3 + ... + 100 =
  1. 5000
  2. 5050
  3. 10000
  4. 100

Answer: (B) 5050 — S₁₀₀ = 100×101/2 = 5050. Gauss's formula: Sₙ = n(n+1)/2.

Q7. The 10th term of AP: 100, 97, 94, ... is:
  1. 73
  2. 76
  3. 70
  4. 79

Answer: (A) 73 — a=100, d=−3. a₁₀ = 100 + 9×(−3) = 100 − 27 = 73.

Q8. In an AP, if first term = 7, last term = 49 and sum = 420, number of terms =
  1. 12
  2. 15
  3. 14
  4. 10

Answer: (B) 15 — S = n(a+l)/2 → 420 = n×56/2 = 28n → n = 15.

Q9. Which term of AP 3, 10, 17, ... is 59?
  1. 9th
  2. 8th
  3. 10th
  4. 7th

Answer: (A) 9th — aₙ = 59 → 3+(n−1)7 = 59 → (n−1)7=56 → n−1=8 → n=9.

Q10. If a, b, c are in AP, then:
  1. a+c = 2b
  2. a−c = 2b
  3. ac = b²
  4. a/c = b

Answer: (A) a+c = 2b — In AP: b−a = c−b → a+c = 2b. The middle term is the arithmetic mean of the other two.

Q11. Sum of first 10 natural numbers =
  1. 45
  2. 55
  3. 50
  4. 100

Answer: (B) 55 — S = n(n+1)/2 = 10×11/2 = 55.

Q12. For the AP: 2, 5, 8, 11, ..., the common difference is:
  1. 2
  2. 3
  3. 5
  4. 8

Answer: (B) 3 — d = 5−2 = 3 (or 8−5 = 3). Common difference is constant = 3.
