About this chapter

A differential equation relates a function to its derivatives. The chapter covers order and degree, forming the general and particular solutions, and three solution methods: variables separable, homogeneous equations (using y = vx) and linear first-order equations solved with an integrating factor. Most board questions ask you to identify the type of equation and solve it step by step.

Answers & explanations — Differential Equations

Try the quiz above first, then open each question to check the answer and the reasoning.

Q1. Order of differential equation d²y/dx² + (dy/dx)³ = x is:
  1. 1
  2. 2
  3. 3
  4. 4

Answer: (B) 2 — Order = highest order derivative present = 2 (d²y/dx²).

Q2. Degree of differential equation (d²y/dx²)³ + dy/dx = x is:
  1. 1
  2. 2
  3. 3
  4. Undefined

Answer: (C) 3 — Degree = power of highest order derivative when polynomial in derivatives = 3 (cube of d²y/dx²).

Q3. General solution of dy/dx = y is:
  1. y = x + C
  2. y = Ceˣ
  3. y = e^C
  4. y = Cx

Answer: (B) y = Ceˣ — Separable: dy/y = dx → ln|y| = x + C → y = Aeˣ.

Q4. An exact differential equation M dx + N dy = 0 satisfies:
  1. ∂M/∂x = ∂N/∂y
  2. ∂M/∂y = ∂N/∂x
  3. M = N
  4. MN = 1

Answer: (B) ∂M/∂y = ∂N/∂x — Exactness condition: ∂M/∂y = ∂N/∂x.

Q5. Integrating factor for linear ODE dy/dx + Py = Q is:
  1. e^(∫Q dx)
  2. e^(∫P dx)
  3. e^P
  4. 1/P

Answer: (B) e^(∫P dx) — IF = e^(∫P dx). Multiplying by IF makes the LHS an exact derivative.

Q6. Homogeneous differential equation has the property:
  1. f(tx, ty) = tⁿ f(x,y)
  2. f(x,y) = f(y,x)
  3. f is linear
  4. f depends on x only

Answer: (A) f(tx, ty) = tⁿ f(x,y) — Homogeneous: f(tx,ty) = tⁿf(x,y). Substitution y = vx solves it.

Q7. Solution of dy/dx = x/y is:
  1. y² = x² + C
  2. y² − x² = C
  3. y = x + C
  4. y² = 2x + C

Answer: (B) y² − x² = C — y dy = x dx → y²/2 = x²/2 + C → y² − x² = C (or 2C).

Q8. Number of arbitrary constants in general solution of a 2nd order ODE:
  1. 1
  2. 2
  3. 3
  4. 0

Answer: (B) 2 — Order n ODE has general solution with n arbitrary constants.

Q9. dy/dx + 2y = 4 is a linear ODE. Its solution is:
  1. y = 2 + Ce⁻²ˣ
  2. y = 2 + Ce²ˣ
  3. y = 4 + Ce⁻ˣ
  4. y = Ce⁻²ˣ

Answer: (A) y = 2 + Ce⁻²ˣ — IF = e²ˣ. e²ˣy = ∫4e²ˣdx = 2e²ˣ + C → y = 2 + Ce⁻²ˣ.

Q10. Newton's law of cooling is modelled by:
  1. dT/dt = k(T−T₀)
  2. dT/dt = kT
  3. T = T₀e^(kt)
  4. dT/dt = k/T

Answer: (A) dT/dt = k(T−T₀) — dT/dt = k(T−T₀) where T₀ is ambient temperature, k<0 for cooling.

Q11. Particular solution is obtained from general solution by:
  1. Differentiating once more
  2. Using initial/boundary conditions
  3. Integrating again
  4. Setting C=0 always

Answer: (B) Using initial/boundary conditions — Particular solution uses given conditions (e.g., y(0)=1) to find specific value of arbitrary constant(s).

Q12. The equation dy/dx = (x+y)/(x−y) is:
  1. Separable
  2. Linear
  3. Homogeneous
  4. Exact as-is

Answer: (C) Homogeneous — f(tx,ty) = (tx+ty)/(tx−ty) = t(x+y)/t(x−y) = (x+y)/(x−y) = t⁰f(x,y) → homogeneous of degree 0.
