About this chapter

Matrices and determinants give a compact way to handle systems of linear equations. The unit covers types of matrices, matrix operations, transpose, symmetric and skew-symmetric matrices, determinants and their properties, adjoint and inverse, and solving equations using A⁻¹B. Questions on finding an inverse and solving a 3 × 3 system appear in almost every paper.

Answers & explanations — Matrices & Determinants

Try the quiz above first, then open each question to check the answer and the reasoning.

Q1. For matrix A of order m×n and B of order n×p, the order of AB is:
  1. m×p
  2. n×n
  3. m×n
  4. p×m

Answer: (A) m×p — Matrix multiplication A(m×n) × B(n×p) = AB(m×p). Inner dimensions must match.

Q2. If A is a square matrix, then A + Aᵀ is always:
  1. Skew-symmetric
  2. Symmetric
  3. Null matrix
  4. Identity

Answer: (B) Symmetric — (A+Aᵀ)ᵀ = Aᵀ+A = A+Aᵀ. So A+Aᵀ is symmetric.

Q3. det(AB) =
  1. det(A) + det(B)
  2. det(A) × det(B)
  3. det(A) − det(B)
  4. det(A)/det(B)

Answer: (B) det(A) × det(B) — Multiplicative property of determinants: det(AB) = det(A)·det(B).

Q4. A matrix A is invertible if and only if:
  1. A is symmetric
  2. det(A) ≠ 0
  3. A is square
  4. Trace(A) > 0

Answer: (B) det(A) ≠ 0 — A⁻¹ exists ⟺ |A| ≠ 0 (non-singular matrix).

Q5. If |A| = 5 for 2×2 matrix, then |2A| =
  1. 10
  2. 20
  3. 40
  4. 5

Answer: (B) 20 — For n×n matrix: |kA| = kⁿ|A|. Here n=2, k=2: |2A| = 4×5 = 20.

Q6. The number of elements in a 3×4 matrix is:
  1. 7
  2. 12
  3. 3
  4. 4

Answer: (B) 12 — Elements = rows × columns = 3×4 = 12.

Q7. Adjoint of a 2×2 matrix [[a,b],[c,d]] is:
  1. [[d,−b],[−c,a]]
  2. [[d,c],[b,a]]
  3. [[a,b],[c,d]]
  4. [[−a,b],[c,−d]]

Answer: (A) [[d,−b],[−c,a]] — For 2×2: adj(A) = [[d,−b],[−c,a]] (swap diagonal, negate off-diagonal).

Q8. If A is skew-symmetric, then diagonal elements of A are:
  1. All 1
  2. All 0
  3. All positive
  4. Can be anything

Answer: (B) All 0 — Skew-symmetric: A = −Aᵀ, so aᵢᵢ = −aᵢᵢ → 2aᵢᵢ = 0 → aᵢᵢ = 0.

Q9. Cramer's rule is used to solve:
  1. Differential equations
  2. System of linear equations
  3. Quadratic equations
  4. Inequalities

Answer: (B) System of linear equations — Cramer's rule solves AX = B using determinants: xᵢ = |Aᵢ|/|A|.

Q10. If det(A) = 0, the matrix A is called:
  1. Orthogonal
  2. Singular
  3. Symmetric
  4. Idempotent

Answer: (B) Singular — Singular matrix: |A| = 0, non-invertible.

Q11. Cofactor Cᵢⱼ = (−1)^(i+j) × Mᵢⱼ where Mᵢⱼ is the:
  1. Element aᵢⱼ
  2. Minor of aᵢⱼ
  3. Adjoint element
  4. Trace

Answer: (B) Minor of aᵢⱼ — Mᵢⱼ is the minor — determinant of the submatrix obtained by deleting row i and column j.

Q12. For AX = B, the solution using inverse is:
  1. X = BA⁻¹
  2. X = A⁻¹B
  3. X = AB⁻¹
  4. X = B⁻¹A

Answer: (B) X = A⁻¹B — AX = B → A⁻¹AX = A⁻¹B → X = A⁻¹B.
