About this chapter

Artificial Intelligence is the ability of machines to learn from data and make decisions that normally need human thinking. This chapter separates AI from ordinary automation, introduces the three domains of AI — Data Science, Computer Vision and Natural Language Processing — and looks at everyday uses such as voice assistants, recommendations and face unlock. Expect board questions that ask you to classify an application into its domain or to tell AI apart from simple programmed rules.

Answers & explanations — Introduction to Artificial Intelligence

Try the quiz above first, then open each question to check the answer and the reasoning.

Q1. Artificial Intelligence (AI) is best defined as:
  1. Making robots that look like humans
  2. Simulation of human intelligence by machines
  3. Programming computers to do only arithmetic
  4. Internet of Things

Answer: (B) Simulation of human intelligence by machines — AI = simulation of human intelligence processes by machines, including learning, reasoning and self-correction.

Q2. Which of the following is an application of AI?
  1. A simple calculator
  2. Voice assistant like Siri or Alexa
  3. A USB drive
  4. A power bank

Answer: (B) Voice assistant like Siri or Alexa — Voice assistants (Siri, Alexa, Google Assistant) use NLP and ML — classic AI applications.

Q3. The AI Project Cycle begins with:
  1. Model building
  2. Data collection
  3. Problem scoping
  4. Deployment

Answer: (C) Problem scoping — AI Project Cycle: Problem Scoping → Data Collection → Data Exploration → Modelling → Evaluation → Deployment.

Q4. Natural Language Processing (NLP) enables computers to:
  1. Draw images
  2. Understand and process human language
  3. Solve maths problems
  4. Control hardware

Answer: (B) Understand and process human language — NLP: a branch of AI that allows computers to understand, interpret, and generate human language.

Q5. Computer Vision is used to:
  1. Improve computer display
  2. Enable machines to interpret and understand visual information
  3. Connect computers
  4. Design websites

Answer: (B) Enable machines to interpret and understand visual information — Computer Vision: AI field that trains computers to interpret images and videos (e.g., facial recognition, medical imaging).

Q6. Which of the following best describes Machine Learning?
  1. Machines that physically learn
  2. Systems that learn from data to improve performance without being explicitly programmed
  3. Teaching children to use computers
  4. Programming every possible rule

Answer: (B) Systems that learn from data to improve performance without being explicitly programmed — ML: subset of AI where systems learn patterns from data and improve automatically through experience.

Q7. A self-driving car is an example of which type of AI application?
  1. NLP
  2. Computer Vision + Decision Making
  3. Database Management
  4. Spreadsheet automation

Answer: (B) Computer Vision + Decision Making — Self-driving cars use computer vision (cameras/sensors), ML models and decision-making algorithms.

Q8. The term 'bias in AI' refers to:
  1. Computer hardware defect
  2. Unfair outcomes due to skewed training data or flawed algorithm
  3. Internet connection issue
  4. High processing speed

Answer: (B) Unfair outcomes due to skewed training data or flawed algorithm — AI bias: when an AI system produces unfair results, often because training data is not representative or the algorithm has flaws.

Q9. Which organisation published AI curriculum for CBSE Class 10?
  1. Google
  2. Intel & CBSE
  3. Microsoft
  4. Amazon

Answer: (B) Intel & CBSE — CBSE's AI curriculum for Classes 8–10 was developed in partnership with Intel.

Q10. Recommendation systems (like Netflix/YouTube suggestions) use:
  1. Random selection
  2. Machine Learning to analyse past behaviour
  3. Manual curation only
  4. Internet search

Answer: (B) Machine Learning to analyse past behaviour — Collaborative filtering and content-based ML algorithms analyse viewing history and preferences to suggest content.

Q11. Which of the following is NOT a domain of AI?
  1. Computer Vision
  2. Natural Language Processing
  3. Robotics
  4. Spreadsheet Formatting

Answer: (D) Spreadsheet Formatting — AI domains include NLP, Computer Vision, Robotics, ML, Expert Systems. Spreadsheet formatting is basic software use.

Q12. Ethical AI principles include:
  1. Maximising profit only
  2. Fairness, transparency, accountability and privacy
  3. Speed above all else
  4. Replacing all human jobs

Answer: (B) Fairness, transparency, accountability and privacy — Ethical AI: Fair, Transparent, Accountable, Inclusive, Robust, Secure, Privacy-preserving — key principles globally adopted.
