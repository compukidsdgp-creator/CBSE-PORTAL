About this chapter

Integration is the reverse of differentiation and also a tool for finding areas. The chapter covers standard integrals, integration by substitution, partial fractions and integration by parts, and definite integrals with their properties. Board papers include several integration questions, so learn the standard forms well and practise choosing the right method quickly.

Answers & explanations — Integrals

Try the quiz above first, then open each question to check the answer and the reasoning.

Q1. ∫x² dx equals:
  1. x³
  2. x³/3 + C
  3. 3x + C
  4. 2x + C

Answer: (B) x³/3 + C — Power rule: ∫xⁿ dx = xⁿ⁺¹/(n+1) + C. For n=2: x³/3 + C.

Q2. ∫eˣ dx equals:
  1. eˣ/x + C
  2. xeˣ + C
  3. eˣ + C
  4. eˣ⁺¹ + C

Answer: (C) eˣ + C — The exponential function is its own integral: ∫eˣ dx = eˣ + C.

Q3. ∫sinx dx equals:
  1. cosx + C
  2. −cosx + C
  3. sinx + C
  4. −sinx + C

Answer: (B) −cosx + C — ∫sinx dx = −cosx + C. (Derivative of −cosx is sinx.)

Q4. By parts: ∫u dv = uv − ∫v du. Evaluate ∫x eˣ dx:
  1. xeˣ + C
  2. eˣ(x−1) + C
  3. eˣ(x+1) + C
  4. xeˣ − eˣ + C

Answer: (B) eˣ(x−1) + C — u=x, dv=eˣdx → du=dx, v=eˣ. ∫xeˣdx = xeˣ − ∫eˣdx = xeˣ − eˣ = eˣ(x−1) + C.

Q5. ∫₀^(π/2) sinx dx equals:
  1. 0
  2. 1
  3. 2
  4. π

Answer: (B) 1 — [−cosx]₀^(π/2) = −cos(π/2) + cos(0) = 0 + 1 = 1.

Q6. ∫1/x dx equals:
  1. x² + C
  2. ln|x| + C
  3. 1/x² + C
  4. eˣ + C

Answer: (B) ln|x| + C — ∫1/x dx = ln|x| + C. Valid for x≠0.

Q7. ∫₋ₐᵃ f(x) dx = 2∫₀ᵃ f(x) dx if f is:
  1. Odd function
  2. Even function
  3. Constant
  4. Periodic

Answer: (B) Even function — For even function f(−x)=f(x), the integral from −a to a = 2 × integral from 0 to a.

Q8. Substitution method: ∫f(g(x))g'(x)dx. For ∫2x·(x²+1)⁵dx, substitution is:
  1. u = x²
  2. u = x²+1
  3. u = 2x
  4. u = (x²+1)⁵

Answer: (B) u = x²+1 — Let u = x²+1, then du = 2x dx. Integral becomes ∫u⁵ du = u⁶/6 + C = (x²+1)⁶/6 + C.

Q9. ∫cos²x dx equals:
  1. sin²x/2 + C
  2. x/2 + sin2x/4 + C
  3. −sin2x/4 + C
  4. cos²x/2 + C

Answer: (B) x/2 + sin2x/4 + C — cos²x = (1+cos2x)/2. ∫cos²x dx = x/2 + sin2x/4 + C.

Q10. Area bounded by y = x² and y = x (from x=0 to x=1) is:
  1. 1/6
  2. 1/3
  3. 1/2
  4. 1

Answer: (A) 1/6 — Area = ∫₀¹(x − x²)dx = [x²/2 − x³/3]₀¹ = 1/2 − 1/3 = 1/6.

Q11. ∫sec²x dx =
  1. tanx + C
  2. secx·tanx + C
  3. −cotx + C
  4. cosecx + C

Answer: (A) tanx + C — d(tanx)/dx = sec²x, so ∫sec²x dx = tanx + C.

Q12. Fundamental theorem of calculus: if F'(x) = f(x) then ∫ₐᵇ f(x) dx =
  1. F(a) − F(b)
  2. F(b) + F(a)
  3. F(b) − F(a)
  4. f(b) − f(a)

Answer: (C) F(b) − F(a) — ∫ₐᵇ f(x)dx = [F(x)]ₐᵇ = F(b) − F(a).
