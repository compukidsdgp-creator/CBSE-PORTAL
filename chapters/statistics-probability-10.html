About this chapter

Statistics in Class 10 is about finding the mean, median and mode of grouped data using the direct, assumed-mean and step-deviation methods. The probability part covers classical probability for single events, with dice, coins and cards as typical examples. Practise the mode and median formulas for grouped data — they appear almost every year.

Answers & explanations — Statistics & Probability

Try the quiz above first, then open each question to check the answer and the reasoning.

Q1. Mean of 2, 4, 6, 8, 10 is:
  1. 5
  2. 6
  3. 7
  4. 4

Answer: (B) 6 — Mean = (2+4+6+8+10)/5 = 30/5 = 6.

Q2. Median of 3, 5, 7, 9, 11 (n=5) is:
  1. 5
  2. 7
  3. 9
  4. 6

Answer: (B) 7 — Arranged in order; median = middle value = 3rd value = 7.

Q3. Mode is the value that:
  1. Appears least frequently
  2. Appears most frequently
  3. Is in the middle
  4. Is the average

Answer: (B) Appears most frequently — Mode = most frequently occurring value in a data set.

Q4. Empirical relationship between mean, median and mode is:
  1. Mean − Mode = 2(Mean − Median)
  2. Mode = 3 Median − 2 Mean
  3. Mean + Mode = 2 Median
  4. None

Answer: (B) Mode = 3 Median − 2 Mean — Empirical: Mode ≈ 3 Median − 2 Mean (for moderately asymmetric distributions).

Q5. Probability P(E) of an event E always satisfies:
  1. 0 < P(E) < 1
  2. 0 ≤ P(E) ≤ 1
  3. P(E) > 1 is possible
  4. P(E) = 1 always

Answer: (B) 0 ≤ P(E) ≤ 1 — Probability ranges from 0 (impossible) to 1 (certain): 0 ≤ P(E) ≤ 1.

Q6. A card is drawn from a deck of 52. P(ace) =
  1. 1/52
  2. 4/52 = 1/13
  3. 1/4
  4. 4/13

Answer: (B) 4/52 = 1/13 — 4 aces in 52 cards. P = 4/52 = 1/13.

Q7. Cumulative frequency is used to draw:
  1. Bar graph
  2. Histogram
  3. Ogive
  4. Frequency polygon

Answer: (C) Ogive — Ogive (cumulative frequency curve) is plotted using cumulative frequencies vs. class boundaries.

Q8. If P(A) = 0.4, then P(not A) =
  1. 0.4
  2. 0.6
  3. 1
  4. 0

Answer: (B) 0.6 — P(A') = 1 − P(A) = 1 − 0.4 = 0.6.

Q9. Class mark (mid-point) of class 20−30 is:
  1. 20
  2. 25
  3. 30
  4. 10

Answer: (B) 25 — Class mark = (lower limit + upper limit)/2 = (20+30)/2 = 25.

Q10. Median using ogive is found at cumulative frequency:
  1. n/4
  2. n/2
  3. 3n/4
  4. n

Answer: (B) n/2 — Median corresponds to the n/2 cumulative frequency on the ogive (Q2 = 50th percentile).

Q11. A bag has 5 red and 3 blue balls. P(blue ball) =
  1. 5/8
  2. 3/8
  3. 3/5
  4. 1/3

Answer: (B) 3/8 — P(blue) = 3/(5+3) = 3/8.

Q12. For grouped data, Mean = Σfᵢxᵢ/Σfᵢ. If Σfᵢ = 50 and Σfᵢxᵢ = 1000, Mean =
  1. 500
  2. 20
  3. 50
  4. 1000

Answer: (B) 20 — Mean = 1000/50 = 20.
