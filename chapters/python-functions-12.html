About this chapter

Functions let you write a block of code once and reuse it. This chapter covers defining functions, parameters and arguments (positional, default and keyword), return values, the scope of variables, and using built-in and user-defined modules such as math and random. Output-tracing questions and short function-writing tasks are common.

Answers & explanations — Python Functions & Modules

Try the quiz above first, then open each question to check the answer and the reasoning.

Q1. Which keyword is used to define a function in Python?
  1. fun
  2. define
  3. def
  4. function

Answer: (C) def — Python uses 'def' keyword to define a function: def function_name(parameters):

Q2. What is the output of: def f(x, y=10): return x+y → print(f(5))
  1. Error
  2. 5
  3. 15
  4. 10

Answer: (C) 15 — y has default value 10. f(5) → x=5, y=10 → returns 5+10=15.

Q3. A function that calls itself is called:
  1. Lambda function
  2. Recursive function
  3. Generator
  4. Decorator

Answer: (B) Recursive function — Recursion: a function that calls itself with a simpler sub-problem until a base case is reached.

Q4. What does *args in a function definition allow?
  1. No arguments
  2. Keyword arguments only
  3. Variable number of positional arguments
  4. Exactly 2 arguments

Answer: (C) Variable number of positional arguments — *args collects any number of positional arguments into a tuple inside the function.

Q5. The scope of a variable defined inside a function is:
  1. Global
  2. Local
  3. Built-in
  4. Enclosing

Answer: (B) Local — Variables defined inside a function have local scope — they exist only within that function.

Q6. lambda x: x**2 is equivalent to:
  1. def f(): return x**2
  2. def f(x): return x**2
  3. def f(x): x**2
  4. lambda: x**2

Answer: (B) def f(x): return x**2 — Lambda is an anonymous single-expression function. lambda x: x**2 equals def f(x): return x**2.

Q7. Which built-in function returns the number of items in a list?
  1. size()
  2. count()
  3. len()
  4. num()

Answer: (C) len() — len(list) returns the number of elements. It works on lists, tuples, strings, dicts, etc.

Q8. What is the output of: print(type(lambda x: x))
  1. <class 'function'>
  2. <class 'lambda'>
  3. <class 'method'>
  4. Error

Answer: (A) <class 'function'> — Lambda functions are of type 'function' in Python, same as regular def functions.

Q9. The 'return' statement in a function:
  1. Prints a value
  2. Ends the program
  3. Sends a value back to the caller
  4. Loops back to start

Answer: (C) Sends a value back to the caller — return exits the function and optionally sends a value back to where the function was called.

Q10. To import only the sqrt function from math module:
  1. import math.sqrt
  2. from math import sqrt
  3. include math.sqrt
  4. use math(sqrt)

Answer: (B) from math import sqrt — from math import sqrt imports only sqrt, so you can use it directly without math.sqrt prefix.

Q11. What is a module in Python?
  1. A loop structure
  2. A file containing Python definitions and statements
  3. A data type
  4. A class method

Answer: (B) A file containing Python definitions and statements — A module is a .py file containing Python code (functions, classes, variables) that can be imported and reused.

Q12. Global variable inside a function can be modified using:
  1. local keyword
  2. global keyword
  3. extern keyword
  4. public keyword

Answer: (B) global keyword — global x inside a function allows modification of the global variable x. Without it, assignment creates a new local variable.
