About this chapter

This chapter turns differentiation into a problem-solving tool. You will use derivatives to find rates of change, decide where a function is increasing or decreasing, and locate local maxima and minima with the first and second derivative tests. Word problems on maximising area or volume and minimising cost carry high marks, so practise setting up the function carefully before differentiating. Tangents and normals are no longer in the rationalised syllabus.

Answers & explanations — Application of Derivatives

Try the quiz above first, then open each question to check the answer and the reasoning.

Q1. A function f(x) is increasing at x = a if:
  1. f'(a) < 0
  2. f'(a) = 0
  3. f'(a) > 0
  4. f''(a) > 0

Answer: (C) f'(a) > 0 — f is increasing ⟺ f'(x) > 0.

Q2. The slope of tangent to y = x³ at x = 2 is:
  1. 4
  2. 8
  3. 12
  4. 3

Answer: (C) 12 — y' = 3x². At x=2: slope = 3×4 = 12.

Q3. For local maximum, necessary and sufficient conditions are:
  1. f'(a) = 0 only
  2. f'(a) = 0 and f''(a) < 0
  3. f'(a) = 0 and f''(a) > 0
  4. f''(a) < 0 only

Answer: (B) f'(a) = 0 and f''(a) < 0 — Second derivative test: f'(a)=0 and f''(a)<0 → local max; f''(a)>0 → local min.

Q4. A particle moves as s = t³ − 3t + 2. Its velocity at t=1 is:
  1. 0
  2. 1
  3. 3
  4. −3

Answer: (A) 0 — v = ds/dt = 3t² − 3. At t=1: v = 3−3 = 0.

Q5. The equation of normal to y = x² at (1,1) is:
  1. y = 2x−1
  2. y = −x/2 + 3/2
  3. y = x + 1
  4. y = x − 1

Answer: (B) y = −x/2 + 3/2 — y'=2x; slope of tangent at (1,1) = 2. Slope of normal = −1/2. Normal: y−1 = −1/2(x−1) → y = −x/2 + 3/2.

Q6. If f'(x) = 0 at x = a and doesn't change sign, then x = a is:
  1. Local maximum
  2. Local minimum
  3. Point of inflection
  4. Absolute maximum

Answer: (C) Point of inflection — If f' doesn't change sign at critical point, it's a point of inflection (not local extremum).

Q7. The function f(x) = sinx on [0,π] has absolute maximum at:
  1. x = 0
  2. x = π
  3. x = π/2
  4. x = π/4

Answer: (C) x = π/2 — sin(π/2) = 1 is maximum on [0,π].

Q8. Rolle's theorem requires f to be continuous on [a,b], differentiable on (a,b), and:
  1. f(a) = f(b) = 0
  2. f(a) = f(b)
  3. f'(a) = f'(b)
  4. f(a) > f(b)

Answer: (B) f(a) = f(b) — Rolle's theorem: if f(a)=f(b), then ∃c∈(a,b) such that f'(c)=0.

Q9. Lagrange's Mean Value Theorem guarantees a point c where:
  1. f'(c) = 0
  2. f'(c) = [f(b)−f(a)]/(b−a)
  3. f(c) = [f(a)+f(b)]/2
  4. f''(c) = 0

Answer: (B) f'(c) = [f(b)−f(a)]/(b−a) — LMVT: f'(c) = [f(b)−f(a)]/(b−a). The instantaneous rate equals average rate at some point.

Q10. Increasing/decreasing intervals of f(x) = x³ − 3x on ℝ: f decreases on:
  1. (−∞,∞)
  2. (−1,1)
  3. (−∞,−1)∪(1,∞)
  4. (0,∞)

Answer: (B) (−1,1) — f'(x) = 3x²−3 = 3(x−1)(x+1). f'<0 when −1<x<1, so f decreases on (−1,1).

Q11. Approximate value using derivative: √(26) ≈ (let f(x)=√x, x=25, Δx=1):
  1. 5.1
  2. 5.2
  3. 5.0
  4. 4.9

Answer: (A) 5.1 — f(26) ≈ f(25) + f'(25)×1 = 5 + (1/10)×1 = 5.1.

Q12. In an optimization problem, after finding critical point, we verify minimum/maximum using:
  1. First derivative test only
  2. Second derivative test
  3. Both first and second derivative tests
  4. Rolle's theorem

Answer: (C) Both first and second derivative tests — Both tests can be used. Second derivative test is quicker; first derivative test is more conclusive when f'' = 0.
